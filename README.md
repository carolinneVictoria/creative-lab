# 🎨 Creative Lab

**Transformando formas, cores e algoritmos em arte generativa.**

O Creative Lab é uma aplicação web de arte generativa que permite criar composições abstratas únicas por meio da combinação de formas geométricas, elementos orgânicos, cores, padrões e texturas.

A proposta é oferecer um pequeno laboratório criativo onde o usuário pode experimentar diferentes parâmetros visuais, explorar combinações e transformar suas ideias em composições digitais.

As imagens são geradas proceduralmente por meio de algoritmos visuais, sem depender de inteligência artificial generativa.

Link do projeto na vercel: https://criative-lab-navy.vercel.app/

## ✨ Funcionalidades

- **Geração de arte:** criação procedural de composições abstratas a partir de parâmetros configuráveis.
- **Estilos visuais:** exploração de formas orgânicas, composições geométricas e arte abstrata.
- **Personalização:** controle da quantidade e do tamanho das formas, das cores e do fundo.
- **Paletas de cores:** experimentação com diferentes combinações cromáticas.
- **Composição visual:** controle de sobreposição, distribuição dos elementos e gradientes.
- **Pré-visualização:** visualização das composições diretamente na interface.
- **Exportação de imagens:** possibilidade de exportar as criações em PNG e SVG.
- **Exploração criativa:** geração de novas variações a partir das configurações escolhidas.

## 🧠 Como funciona a geração de arte?

O Creative Lab utiliza **arte generativa procedural**: em vez de desenhar cada elemento manualmente, um algoritmo cria composições a partir de regras e parâmetros visuais.

O processo funciona em etapas:

1. **Configuração:** o usuário define o estilo, as cores, a quantidade e o tamanho dos elementos.
2. **Geração:** o algoritmo seleciona formas, posições, dimensões e variações visuais.
3. **Composição:** regras de distribuição, sobreposição e preenchimento organizam os elementos na tela.
4. **Renderização:** os elementos são desenhados em SVG para formar a imagem final.
5. **Exportação:** a composição pode ser convertida em um arquivo de imagem.

A combinação desses fatores permite gerar diferentes resultados mesmo utilizando um conjunto limitado de formas e cores.

## 🎨 Estilos visuais

O projeto explora diferentes abordagens de composição:

- **Orgânico:** formas fluidas, curvas e elementos irregulares.
- **Geométrico:** círculos, anéis, polígonos, triângulos e outras formas definidas.
- **Abstrato:** combinações de elementos, cores, gradientes e sobreposições para criar composições experimentais.

## 💻 Executando o projeto

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório:

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta do projeto:

```bash
cd creative-lab
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse o endereço indicado no terminal para visualizar a aplicação.
